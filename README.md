# ZMK Firmware — Charybdis Mini MOD 42-Key (`3×6 + 3/3`, `V&Z-MINI36M`)

Современная полнофункциональная прошивка **ZMK (`main` / Zephyr 4.1 HWMv2)**, созданная на основе побайтового реверс-инжиниринга заводских прошивок `miniMOD36-studio.zip` специально для редкой 42-клавишной модификации **Charybdis Mini MOD** (**3×6 + по 3 клавиши тамб-кластера на каждой половине**).

Подробный отчёт о распиновке и отличиях вашей платы от обычных Charybdis Mini см. в [`HARDWARE_ANALYSIS.md`](./HARDWARE_ANALYSIS.md).

---

## Главные возможности сборки

- **100% точное совпадение с «железом» `V&Z-MINI36M`**: правильные сдвинутые строки матрицы (`D21, D18, D5, D4`), разблокировка обоих NFC-пинов (`P0.09` и `P0.10` через `&uicr`), симметричный тамб-кластер `3+3` (42 клавиши), точная ориентация трекбола **PMW3610** и адресная подсветка **WS2812** (по 21 LED на половину с отсечкой тока покоя через `EXT_POWER`).
- **Два режима работы на выбор**:
  1. **Автономный режим БЕЗ донгла** — правая половина выступает главной (`Central`), подключается к ПК/планшету по Bluetooth (до 5 профилей) или USB.
  2. **Режим с беспроводным USB-Донглом** (`nice!nano v2` или миниатюрный `Seeed XIAO nRF52840 BLE`) — донгл выступает главным (`Central`), а **обе половины работают как экономичные `Peripheral`**, увеличивая время автономной работы правой половины с трекболом в несколько раз и снижая радиозадержку!
- **Полная поддержка ZMK Studio (`https://zmk.studio/`)**:
  - Эргономичная визуальная схема Charybdis 3×6+3 с веерным расположением тамб-кластеров.
  - Изменение любых клавиш и слоёв «на лету» без перекомпиляции прошивки (работает и напрямую на правой половине, и через USB-донгл!).
  - Три дополнительных резервных слоя (`extra1..extra3`), готовых к активации в ZMK Studio.
- **Продвинутый конвейер трекбола (ZMK Input Processors)**:
  - **Auto-Mouse (`L_MOUSE`)** с защитой от случайных касаний при быстрой печати (`require-prior-idle-ms = <200>`): стоит сдвинуть шар — под пальцами левой и правой руки автоматически включаются кнопки мыши (`LCLK`, `MCLK`, `RCLK`, `MB4`, `MB5`); стоит нажать любую букву — слой мгновенно исчезает и печатается буква.
  - **Плавный 2D-скролл (`L_SCROLL`)**: вертикальная и горизонтальная прокрутка шаром с поддержкой `ZMK_POINTING_SMOOTH_SCROLLING`.
  - **Снайперский режим (`L_SNIPE`)**: замедление курсора `1:3` для попиксельной точности.
- **Удобство для русского (ЙЦУКЕН) и английского (QWERTY) набора**:
  - Все **33 буквы русского алфавита** (`Ё`, `Х`, `Ъ`, `Ж`, `Э`, `Б`, `Ю`) помещаются прямо на основном слое 3×6 без переключения слоёв!
  - Позиционные **Timeless Home-Row Mods** (`A/S/D/F` и `J/K/L/;` — с защитой от ложных срабатываний при наборе одной рукой) + мгновенно включаемый чистый слой **`Raw/Game` без HRM** (одновременное нажатие двух внутренних тамб-клавиш `38 + 39`).

## Быстрая сборка прошивки (2 способа)

### Способ 1: В облаке через GitHub Actions (рекомендуется, ничего устанавливать не нужно)
1. Создайте новый репозиторий на GitHub и загрузите туда содержимое этой папки (`Charybdis`):
   ```powershell
   git init
   git add .
   git commit -m "Initial ZMK config for Charybdis Mini MOD 42-key"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions** в вашем репозитории на GitHub.
3. По завершении сборки (~3 минуты) скачайте архив **`firmware.zip`** со всеми готовыми `.uf2` файлами!

### Способ 2: Локальная сборка через `west` / Docker
```bash
west init -l config
west update
west zephyr-export

# Пример сборки правой половины (Central + ZMK Studio):
west build -s zmk/app -d build/right -b nice_nano//zmk -S studio-rpc-usb-uart -- \
  -DZMK_CONFIG="$PWD/config" -DZMK_EXTRA_MODULES="$PWD" \
  -DSHIELD=charybdis_right -DCONFIG_ZMK_STUDIO=y
```

## Какую прошивку куда заливать

При двойном нажатии кнопки `Reset` на контроллере плата монтируется как USB-флешка (`NICENANO` или `XIAO-SENSE`). Просто скопируйте нужный файл `.uf2` на этот диск.

### Вариант А — Работа БЕЗ донгла (по Bluetooth / USB напрямую к ПК)
| Устройство | Файл `.uf2` из архива `firmware` |
| :--- | :--- |
| **Левая половина** | `charybdis_left-nice_nano_v2-zmk.uf2` |
| **Правая половина (Главная)** | `charybdis_right_central_bt-nice_nano_v2-studio.uf2` |

### Вариант Б — Работа С внешним USB-донглом (максимальная автономность)
| Устройство | Файл `.uf2` из архива `firmware` |
| :--- | :--- |
| **Левая половина** | `charybdis_left-nice_nano_v2-zmk.uf2` |
| **Правая половина (Периферия)** | `charybdis_right_peripheral_for_dongle-nice_nano_v2.uf2` |
| **Донгл на `nice!nano v2`** | `charybdis_dongle_central-nice_nano_v2-studio.uf2` |
| *или* **Донгл на `Seeed XIAO BLE`** | `charybdis_dongle_central-xiao_ble-studio.uf2` |

> **ВАЖНО при смене режима (А ↔ Б) или первом переходе со стока:**
> Обязательно сначала прошейте **`settings_reset-nice_nano_v2-zmk.uf2`** (и `settings_reset-xiao_ble-zmk.uf2` на XIAO донгл) на **все** платы, затем залейте боевые прошивки и включите половины одновременно рядом с центральной платой/донглом для автоматического спаривания!

## Работа с ZMK Studio (`https://zmk.studio/`)

1. Подключите главную плату (правую половину в Варианте А **или** USB-донгл в Варианте Б) USB-кабелем к компьютеру.
2. Зажмите внешнюю правую тамб-клавишу (`Del` / слой `Sys/Fn`) и нажмите верхнюю левую угловую клавишу (`Ё / ~` = `&studio_unlock`) — это разблокирует сеанс редактирования.
3. Откройте **[https://zmk.studio/](https://zmk.studio/)** в браузере Chrome / Edge (или скачайте десктопное приложение ZMK Studio) и нажмите **Connect → USB**.
4. Меняйте любые клавиши, переименовывайте слои или активируйте резервные слои — изменения сохраняются в память клавиатуры мгновенно!

## Схема слоёв по умолчанию (`config/charybdis.keymap`)

- **Слой `0` (`Base`)**: Полная раскладка `QWERTY` / `ЙЦУКЕН` (с `Ё` на `00`, `Х` на `11`, `Ж` на `22`, `Э` на `23`, `Ъ` на `35`). На домашнем ряду `A/S/D/F` и `J/K/L/;` — умные модификаторы `GUI / Alt / Shift / Ctrl`.
  - **Левый тамб-кластер (`36, 37, 38`)**: `Esc / Scroll` | `Space / Nav` | `Tab / Mouse`
  - **Правый тамб-кластер (`39, 40, 41`)**: `Enter / Sym` | `Backspace / Num` | `Delete / Sys`
- **Слой `1` (`Raw/Game`)**: Чистый слой без Home-Row Mods (включается/выключается комбо двух внутренних тамб-клавиш `38 + 39`).
- **Слой `2` (`Nav`)**: Стрелки `Left/Down/Up/Right`, `Home/End/PgUp/PgDn`, `Ctrl+Z/X/C/V`, `Win+V` (история буфера), смена языка (`Alt+Shift` и `Win+Space`).
- **Слой `3` (`Num`)**: Удобный Numpad `7-8-9 / 4-5-6 / 1-2-3 / 0` и знаки арифметики.
- **Слой `4` (`Sym`)**: Все спецсимволы программирования и скобки `! @ # $ % ^ & * ( ) [ ] { } < > \ | ~`.
- **Слой `5` (`Sys/Fn`)**: `F1..F12`, управление профилями Bluetooth (`BT 0..4`, `BT_CLR`, `OUT_TOG`), управление подсветкой WS2812 (`RGB_TOG`, эффекты, цвет, яркость), мультимедиа, `&studio_unlock` и вход в `&bootloader`.
- **Слои `6 / 7 / 8` (`Mouse` / `Snipe` / `Scroll`)**: Автоматический слой мыши, режим замедления курсора `1:3` и плавная двумерная прокрутка шаром.

### Полезные тонкие настройки
- **Изменить базовую скорость (CPI) трекбола**: откройте [`boards/shields/charybdis/charybdis_pmw3610.dtsi`](./boards/shields/charybdis/charybdis_pmw3610.dtsi) и измените `cpi = <800>;` (шаг `200`, например `600`, `800`, `1000`, `1200`).
- **Настроить скорость скролла, Snipe или таймер Auto-Mouse**: откройте [`config/charybdis_pointer.dtsi`](./config/charybdis_pointer.dtsi).
